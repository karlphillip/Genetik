values or default grammar lists. Generic GA, executor, candidate preparation,
admission and coordinate-search code are unchanged. The arithmetic interpreter
still traverses children first in postfix order, using lexical scratch and immutable
owned expressions. Only scientific kernels are shared; existing primitive arithmetic
and reduction order remain intact. Power metadata uses the existing private node
index storage, with checked factories/inspection. The extra scalar full-plan limit
is appended to ExpressionLimits, preserving existing aggregate initializers.
ExpressionResult gains an executed-work inspector. Existing scores, invalidity and
row visitation remain unchanged. Scientific functions introduce runtime-qualified
libm results; no cross-platform bitwise trajectory guarantee is added.

Optional file controls expose scientific names/exponents and small bounded
population/structure/discrete settings; omitted settings preserve prior behavior.
Effective concurrency prints after configuration resolution, so a nondefault
population has the correct task ceiling. The file reader remains generic and finite.
No parser, typed-file syntax or new mathematical dependency is introduced.
